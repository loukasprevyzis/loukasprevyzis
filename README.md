## Selected work

**[kube-review](https://github.com/loukasprevyzis/kube-review)** (Go). A static Kubernetes manifest review tool that flags common security, reliability and cost issues before they reach production: `:latest` image tags, missing `runAsNonRoot`, missing probes, missing resource requests and limits. Reviews manifests and rendered Helm charts, outputs text, JSON or SARIF, and works as a CI gate or GitHub Action.
